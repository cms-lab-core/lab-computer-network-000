# Computer Networks 000

Вводная лабораторная без отдельной сетевой темы.

Стенд содержит два заранее настроенных Linux-хоста:

```text
pc1 (192.0.2.10/24) — eth1 — eth1 — pc2 (192.0.2.20/24)
```

Откройте `task.ipynb` и проходите работу сверху вниз. Здесь студент осваивает notebook, terminal, `%%capture_traffic`, статический вывод PCAP, CHECK, намеренный failed CHECK, диагностику, HINT/RESET и исправление.
